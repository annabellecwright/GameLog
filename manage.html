The manager only runs locally

This page edits the files in data/, which means it needs a server on your own machine that can write to them. A published GameLog is static files on someone else's host. There is nothing there to save to, which is also why nobody visiting your site can change it.

Run it locally:

npm run manage

Then open the address it prints.
